# phsrinivas.github.io

My personal site: https://phsrinivas.github.io/

Plain HTML, CSS and JavaScript. No frameworks, no build step.

- `index.html` has all the text
- `style.css` has the colors (light and dark) and layout
- `script.js` has the dark mode button

To add a project, copy one `<div class="project">` block in `index.html` and change it.

To preview it on your computer, open `index.html` in a browser.
